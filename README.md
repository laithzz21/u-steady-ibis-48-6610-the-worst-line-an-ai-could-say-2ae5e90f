# The Worst Line an AI Could Say

A make.fun bounty entry: a single pickup line, the worst one an AI could
plausibly deliver. Flat, over-helpful, faintly ominous — the joke sits in the
failure, not in crudeness. The program prints exactly one line and nothing else.

Run it with:

```sh
python3 main.py
```
